┌─────────────────────────────────────────────────────────────────────────┐
│                   CONCEITOS DE POO DEMONSTRADOS                         │
└─────────────────────────────────────────────────────────────────────────┘

1. HERANÇA (Inheritance)
   └─ ItemVenda é superclasse abstrata
   └─ ProdutoFisico, Servico, ProdutoDigital herdam de ItemVenda

2. POLIMORFISMO (Polymorphism)
   └─ Método obterInformacoes() implementado de forma específica em cada classe
   └─ Tratamento uniforme de diferentes tipos através da superclasse

3. ENCAPSULAMENTO (Encapsulation)
   └─ Atributos privados
   └─ Acesso controlado via getters/setters

4. ABSTRAÇÃO (Abstraction)
   └─ ItemVenda define contrato comum
   └─ CarrinhoDeCompras define interface de operações

5. AGREGAÇÃO (Aggregation)
   └─ Loja "tem muitos" ItemVenda
   └─ Itens podem existir independentemente da loja

6. INTERFACE (Interface)
   └─ CarrinhoDeCompras define contrato
   └─ CarrinhoDeComprasImpl fornece implementação concreta

1. Criar Loja

2. Criar Itens de Venda

   ├─ Servico (serviços como entrega)
   └─ ProdutoDigital (vouchers, ingressos)

3. Popular Catálogo
   └─ Adicionar itens ao catálogo da loja

4. Criar Carrinho
   └─ Instanciar CarrinhoDeComprasImpl

5. Adicionar ao Carrinho
   └─ Adicionar itens do catálogo ao carrinho

6. Finalizar Compra
   ├─ Calcular total
   └─ Finalizar compra
